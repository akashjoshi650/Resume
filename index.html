How I build agents

Hybrid routing: OpenAI + Ollama

Each task goes through a router. Light work — classification, extraction, drafts — runs on a local Ollama model at zero cost. Harder reasoning steps go to the OpenAI API. The agent loop calls tools, checks the result, and continues until the task is done.

  • Cuts paid API usage by keeping routine calls local
  • Same tool-calling interface for both providers
  • Served over FastAPI so any frontend can use it
